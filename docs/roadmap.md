# 가중 로드맵과 완료 기준

| 단계 | 가중치 | 완료 수용 기준 |
|---|---:|---|
| 1. 요구사항·보안·데이터 설계 | 10 | 요구사항과 역할·격리·감사·동의 설계 문서; 실제 NAS/그룹 용량 및 운영 정책 의사결정 승인 |
| 2. 실행 앱·DB·테스트·CI 기반 | 15 | 고정 의존성·최소 앱·실제 DB 마이그레이션; RED/GREEN 테스트·로컬 HTTP 검증; 원격 브랜치 CI 성공·독립 검토 |
| 3. 가입 승인·인증·회원 | 20 | 승인 전 접근 거부·역할별 권한·테넌트 격리 테스트; 승인 취소·세션 폐기·감사 기록 |
| 4. NAS 권한·할당량·실사용량 | 25 | 실장비 API 기능 검증·읽기 연동; 권한 변경 승인/보상·쿼터 의미 검증; 갱신시각·수집실패·권한별 실제 사용량 |
| 5. 티켓·라이브 채팅 | 15 | 테넌트별 티켓·메시지 접근 통제; 실시간 전달·재연결·보존/삭제 정책 검증 |
| 6. RustDesk 관리자 웹 지원 | 5 | 지원 방식·라이선스·웹 기능 실제 검증; 동의·만료·접근통제·감사 검증 |
| 7. 실배포·보안·복구 | 10 | 승인된 호스트 배포·TLS·보안 점검; 백업 복구·롤백 실제 훈련 |

문서 존재와 실제 승인/동작/운영 검증은 별개다. docs/progress.json은 구현자 증거이며
부모의 독립 검증 후에만 canonical 완료율에 반영한다. 단계 일부 구현을 단계 전체 완료로 표시하지 않는다.
각 단계 가중치 내 항목별 배점은 부모가 승인하기 전 임의로 부여하지 않는다.
1단계는 설계 초안 작성, 2단계는 개발 기반을 목표로 하며 운영 가능 판정이 아니다.

## 자동 진행과 의사결정 게이트
승인된 범위의 안전하고 되돌릴 수 있는 테스트/내부 리팩터/문서는 자동 진행한다.
중요 분기점만 부모가 선택지와 권장안을 사용자에게 제시하고 미결정 영역만 보류한다.

| 게이트 | 선택지 / 권장안 | 영향·승인 전 제한 |
|---|---|---|
| 배포 대상 | NAS 내부 / 별도 서버; 격리된 별도 서버 우선 검토 | 네트워크·가용성·비용; 외부 배포 금지 |
| 비용·라이선스 | 무료 범위 / 유료 계약; 기능과 라이선스 먼저 검증 | 신규 결제/계약 금지 |
| NAS 실제 권한 변경 | 읽기 전용 검증 → 테스트 폴더 → 운영 적용 권장 | 실제 계정·폴더·quota 수정 금지 |
| 인증·계정 연동 | 포털 독립 계정 / DSM·SSO; 독립 승인 경계 권장 | 운영 계정 생성/연동 정책 확정 보류 |
| RustDesk 연결 | 기존 서비스 링크 / 검증된 웹 클라이언트; capability 검증 우선 | 브라우저 기능·에디션·라이선스 미확인, 연결 변경 금지 |
| 파괴적 변경 | 백업·복구 검증 뒤 명시 승인 권장 | 삭제·권한 회수·데이터 이동/비가역 migration 금지 |

## 진행 알림
부모가 설치한 cron이 한국시간(Asia/Seoul) 07~22시 매 10분 진행 보고를 담당한다.
23:00~07:00 자동 알림 금지. 구현자는 cron/canonical 진행 JSON을 수정하지 않는다.
10분 이상 작업 시 repo 증거를 갱신하고 부모에게 검증 가능한 결과를 전달한다.
