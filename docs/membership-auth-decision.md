# 회원 단계 인증 결정

## 현재 결정: authentik 선택 SSO

사용자의 후속 결정으로 Synology SSO 제안 대신 `sso.keiminem.com`의 authentik OIDC를 사용합니다.
기본 OFF인 선택 인증이며 기존 로컬 계정/비상 관리자/OTP/재인증은 유지합니다.
외부 주체는 issuer+subject로만 매핑하고 이메일 자동 연결이나 IdP 그룹 권한 승격은 하지 않습니다.
신규 주체도 포털 pending 승인과 tenant 권한 경계를 거칩니다. NAS backend 자격증명은 별개입니다.
구현/정확한 callback/미확정 provider/활성화 게이트는 `authentik-oidc.md`를 따릅니다.
아래 날짜별 결정은 역사적 경위이며 현재 SSO 요구를 대체하지 않습니다.


현재 관리자 OTP 등록 요구는 `admin-mfa.md`의 선택 기본(FALSE) DB 정책으로
갱신됐다. 아래 2026-10-12의 무조건 강제 등록 관련 내용은 역사적 결정이며,
선택 bootstrap의 OTP 미등록을 차단조건으로 사용하지 않는다. 확인 완료한
관리자 device의 OTP 요구와 기존 권한 경계는 유지한다.

최신 결정: 2026-10-12 1A/2A/3A/4A 사용자 확정 (`next-decisions.md`). 관리자 OTP 등록·확인·강제의 첫 구현은 `admin-mfa.md` 참조. 배포 서버 `192.168.1.14`/계정 `me0kmin27`은 확정이고 부모 SSH 접속 검증 성공. 후속 사용자 승인으로 Docker 준비와 해당 서버의 loopback 검증 배포만 허용됐다. 공개 포트/운영 개방은 금지이며 `internal-container-deployment.md`의 경계를 따른다. 단독/복수 전체Admin 모두 지원하며 복구 승인 정책 선택·키 백업/훈련은 별도 운영 게이트이고 이전 문구의 custody/hosting 미결정을 대체한다.

## 확정 결정 (2026-10-11)

사용자가 선택지 ①을 명시 승인했다: **포털 계정과 NAS 계정을 분리한다. 웹 가입 → 관리자 승인 → NAS 계정 연결** 순서로 진행한다.
DSM 비밀번호로 포털에 로그인하지 않는다. 후속 구현은 `feat/stage-3-membership`에서 진행했으며 `membership-operations.md` 참조. 최초 결정 리뷰와 후속 구현 증거는 구분한다.

## 비교한 선택지

| 선택지 | 경계 및 결과 | 상태 |
|---|---|---|
| ① 독립 포털 계정 + 승인 후 NAS 연결 | 포털 인증/승인과 NAS 계정·프로비저닝 상태 분리. DSM 비밀번호를 포털 로그인에 사용하지 않음 | 사용자 선택 확정 |
| ② DSM 자격증명으로 포털 로그인 | DSM 인증 API·MFA·잠금·장애 정책 확인 및 NAS 자격증명 취급 필요. 포털 승인 경계는 별도로 필요 | 선택하지 않음, 구현 금지 |

## 후속 구현의 수용 기준

- 포털의 가입/로그인/복구 정책과 NAS 연결 절차 분리. DSM 비밀번호를 포털 비밀번호로 수집·저장·로그인 검증하지 않는다.
- 가입 직후 pending 상태이며 관리자 승인 전 NAS 및 타 회원 정보 접근 거부.
- 승인과 NAS 계정 연결은 별도 상태 및 감사 기록. 승인 성공만으로 NAS 연결 성공을 표시하지 않는다.
- tenant+membership 기준 접근 통제, 교차 tenant 객체 조회·역할 상승·중복 승인 거부 테스트.
- 승인 취소/정지 시 세션과 권한 캐시 무효화, 관리자 재인증/MFA 및 로그인 rate limit 정책.
- custom User 채택 여부와 첫 앱 migration 설계는 회원 구현 전에 결정한다. 현 내장 auth 테이블은 일회 개발 DB 기반이며 운영 데이터가 있다고 가정하지 않는다.
- NAS 계정 연결은 외부 ID 매핑/소유 확인/관리자 승인 기준을 정한 후 구현. 실제 NAS 계정 생성·권한 변경은 별도 승인 필요.

이 결정은 인증 방식만 확정한다. NAS 모델/API/그룹 quota, 회원 개인정보 보존·삭제, 배포 대상, 실제 NAS 변경 권한은 여전히 미결정이다. 1단계 전체 승인이나 3단계 구현 완료로 계산하지 않는다.
